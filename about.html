ABOUT THE FRAMEWORK

What is Tailwind CSS ?

Tailwind CSS is a utility-first framework
used to design and style websites using
ready-made utility classes directly in HTML.

Instead of writing a new CSS rule for every small design change,
you can combine classes such as text-center, p-4 and bg-blue-500.

How Does It Work

Add utility classes to your HTML elements to control their appearance.

<h1 class="text-3xl text-center font-bold">
Hello Tailwind! </h1 >

text-3xl

Makes the text larger.

text-center

Aligns text to the center.

font-bold

Makes the text bold.
